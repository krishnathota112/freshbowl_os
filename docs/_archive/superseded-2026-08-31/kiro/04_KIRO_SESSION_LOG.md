# Kiro prompt 04 · the end-of-session log

**Paste this when a Kiro session is finishing.** It is short on purpose.

---

```text
The session is ending. Write the log now, before you summarise anything to me.

  1  T:\obsidian\memory\sessions\YYYY-MM-DD-<slug>.md
     Format: docs\_templates\SESSION-REPORT.md. Every section, including the empty ones —
     "CONTRACTS CHANGED: none" is a real and useful answer.

  2  T:\obsidian\memory\Now.md
     Rewrite it so it describes this evening, not this morning. Now.md is what the next session
     reads first. If it is stale, the next session starts from a false picture and everything
     after that is wasted.

  3  T:\obsidian\memory\MushroomOS.md
     Add this session to the session list. Update the findings table if a finding opened, moved
     or closed.

  4  New decision?  T:\obsidian\memory\decisions\DEC-0NN-<slug>.md
     Never edit an existing decision file. Supersede it and keep both. The record of a decision
     that was later reversed is worth more than the decision that stuck.

  5  New defect?  T:\obsidian\memory\findings\F<N>-<slug>.md

  6  docs\03-mission\TASK-BOARD.md — claim, complete, or add.

THREE SECTIONS PEOPLE SKIP, IN ORDER OF WHAT THEY COST

  WHAT STOPPED BEING TRUE
    A document that is now wrong. An assumption that was disproved. A workaround no longer
    needed. Nobody writes this section and everybody pays for it.

  WHAT IS STILL UNKNOWN
    "Probed X, did not probe Y." Silence in a report reads as "checked and fine". That is how a
    hole survives an audit.

  WHERE YOU WERE WRONG
    Put it in WHAT STOPPED BEING TRUE. The most valuable lines in this project's history are the
    ones admitting a conclusion moved. Three conclusions changed the moment the deployed database
    was queried instead of read from migration files — and that single note is why every prompt
    now says probe, do not read.

AND THE RULE THIS PROJECT KEEPS RELEARNING

  Superseding is not finished until the old version has moved.

  If this session made a document wrong, move it to docs\_archive\ with its header IN THIS
  SESSION'S COMMIT. Not later. Later is how ten thousand lines of superseded instruction ended up
  sitting exactly where current instructions live, and an agent read them, and rebuilt a
  552-hour process that the factory had already stopped running.

Then, and only then, summarise to me: what became true, what is still unknown, and the exact
next task.
```
