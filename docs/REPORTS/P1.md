# REPORT — P1 · Admin Today

**23 August 2026.** Built by Claude in-session.

## What it replaced

```
Process definition · Activity templates · Evidence requirements · Gates shipped disabled
```

Process-engine metadata on a factory manager's home screen. Its own header admitted the shape was
provisional — *"in the finished product this is today's schedule with start-these and
these-are-running. Neither exists yet — there is no schedule import and no batch."*

True when written. **False by the time anyone read it**: there are batches now, and the honest
placeholder note had become a stale claim about the system's own state. Same class of defect as
C9's lab band, and the second time it has appeared.

The counts are not deleted from the product — they live on `/admin/reference` and
`/admin/process-explorer`, which is where someone goes to ask about the process rather than about
today.

## What it is now

Three questions, in order, and nothing else:

| Band | Source |
|---|---|
| **Starting today** | drafts whose Day 0 is today **or has passed**, with how many things stand between them and activation |
| **Running** | active batches at `Day n · H<hour> of <baseline>` |
| **Needs you** | every blocking finding from `validate_batch`, as its own sentence |

`src/api/adminToday.ts` · `src/routes/AdminToday.tsx` · `tests/adminToday.test.ts` — 10 proofs.

## Four decisions worth stating

**An overdue draft is shown, not filtered.** A batch that should have begun yesterday is *more*
urgent, not less. `start_date <= today`, with the overdue ones on a `crit` rail.

**Null is not zero.** A running batch with nothing recorded renders "not started yet", never
`Day 0 · H0` — which would be a claim about progress that has not happened. Asserted both in the
API (`nowHour === null ? null : batchDay(nowHour)`) and on the screen.

**The finding, not the finding code.** `validate_batch` already writes a sentence naming the
activity and what is wrong with it. Rendering `NO_ASSIGNEE` would be the same mistake this screen
was rewritten to remove. A test asserts the message is what reaches the DOM.

**`validate_batch` is the authority.** The screen asks the same function `activate_batch` consults,
so "3 things to settle" cannot disagree with what activation will actually refuse.

## Today is the factory's day

Computed with `factoryDate(now, factory_clock.timezone)` — the existing helper, reused rather than
reimplemented. That is the one that had the *September-became-January* bug found and fixed in it
during C2, and a second implementation is how the two would drift apart.

The **route** computes it and passes it to the API. An api module importing
`components/composite/geometry` would invert the layering (`UI_COMPONENT_ARCHITECTURE §1`), and a
test asserts `api/adminToday.ts` imports nothing from `components/`.

With no factory timezone the screen refuses to guess: the query is disabled and it states what to
run.

## Links point at the routes that exist

`UI_IMPLEMENTATION_PLAN §1` moves the batch page to `/batch/:id?tab=schedule`. **C4 makes that
move.** Linking there now would have produced a screen of dead links, so these point at
`/admin/batch/:id` and are moved in one place when C4 lands.
